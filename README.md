# 🖥️ Github steps to install this repository to your laptop:
| Step | Instructions |
|------|-------------|
| 1 | Open your desktop terminal. Type `cd Desktop\` to save the repo on your laptop inside the Desktop folder (you can also use `Documents\` or a subfolder on your Desktop). |
| 2 | Type `git clone https://github.com/Parshvibalu/Java-Practice.git` |
| 3 | Open VS Code → **File > Open Folder** → Find the `Java-Practice` folder on your Desktop |
| 4 | Click the **+ file** icon under "Explorer" (top left) and name the file `Array-ArrayList.js` (`.js` creates a JavaScript file — you can code in JavaScript or Java inside here) |

# 📝 NeetCode Steps

Step 1:
Create an account or sign in at neetcode.io\

Step 2:
Click on the HW links below

Step 3:
Read the problem thoroughly. Best practice: Identify the data structure, what the input parameter is, and what output the problem expects (Array? Int? String?)

Step 4:
Draw the data structure and visualize the changes the problem is asking for. How can you do it using basic knowledge of changing numbers or pointers?

Step 5: 
Think of helper methods you can use (e.g., .remove() to remove a number from an array, int var = 5 to initialize a variable, etc.)

Step 6:
Think in pseudocode! Break down the basic steps of manipulating the input in the method parameter — this will represent the code you implement.
Give it a shot! Use the internet to find helper methods or how to initialize things, but do not look up the answer yet.

Step 7: 
💡 After giving it your best shot, go to the Solutions tab and watch the YouTube video for the Java answer. Try to understand where you went wrong (code? conceptually? logic?) and write it in your notes so you can learn!🙌
