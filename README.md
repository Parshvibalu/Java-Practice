# Java-Practice
Creating different .js files to practice coding different data structures in java is key to hands on learning! Follow along the youtube videos and code in VS Code!

GitHub steps to install this repository to your laptop:
Step 1: Open you desktop terminal. Type cd Desktop\ to save your repo on your laptop inside the Desktop folder (can do this in Document\ or inside a Folder on your Desktop\)
Step 2: Type git clone https://github.com/Parshvibalu/Java-Practice.git
Step 3: Open VS Code -> Select Project -> Find the Repo Java-Practice Folder in your Desktop\ 
Step 4: Click on the + file sign and type the name of the file as Array-ArrayList.js (.js files creates a javascript file which is a type of coding language you can code in javascript or java inside here)
